# Bat Siege — milestones (Oct 11 to Nov 2, 2026)

Submissions close **Mon Nov 2, 12:00 PT (2:00 pm Central)**. Voting opens Oct 15, so publishing
early matters. Each milestone ends with a playtest question that must be answered before moving on.

## M0 — Setup (Sun Oct 11 to Mon Oct 12)
- Install Blender 4.2 LTS and RUN's CLI (per RUN's official guide).
- Create the RUN project. Get a "hello world" scene previewing on Zyrus's phone.
- Run the Blender script, fix errors, check every preview PNG.
- **Done when:** the castle frame, one block of each type, and the bat load and render in the RUN project.

## M1 — Core loop with real assets (Tue Oct 13 to Sat Oct 17)
- Port from the prototype: flight, moths, building and stacking, rock drop with landing ring,
  damage and level breaking, completion bars, timer, win/lose.
- Simple AI that gathers, builds, and raids.
- **Playtest question:** "Is choosing between build and raid tense?" If no, tune numbers before anything else.

## M2 — Publish v1 (Sun Oct 18)
- Termites, ghost turrets, blood moon, start and end screens.
- Publish to **public** and enter it with "Enter the jam" so it starts collecting votes.
- **Playtest question:** "Do 3 friends play a second match without being asked?"

## M3 — Juice and feel (Oct 19 to Oct 25)
- Debris, squash and stretch, camera shake, perfect-hit effects, torch flicker, sounds.
- Phone performance pass (60 fps target).
- Visual pass against the concept art.
- **Playtest question:** "Does a new player understand what to do in the first 10 seconds?"

## M4 — Balance and final polish (Oct 26 to Nov 1)
- Tune costs, HP, AI aggression, match length from playtest notes.
- RUN leaderboard for win streak (only if everything above is solid).
- Fix every bug on the list. No new features.

## M5 — Ship (Mon Nov 2, before noon PT)
- Final publish, confirm the entry appears on the jam leaderboard, share the link.
- **Then return to Pug Surf.**
